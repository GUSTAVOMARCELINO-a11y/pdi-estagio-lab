# 📚 Sistema de Biblioteca CLI em Ruby

Projeto desenvolvido em Ruby (Orientação a Objetos e CLI) para controle e gerenciamento de acervo de livros via terminal.

## 🚀 Tecnologias Utilizadas

- **Ruby** (Versão 3.x)
- **IRB** (Interactive Ruby Shell para experimentos e testes)
- **VS Code** (IDE de desenvolvimento)

## 📁 Estrutura do Projeto

```text
ruby-biblioteca-cli/
├── livro.rb         # Classe Livro (Atributos e regras de empréstimo/devolução)
├── biblioteca.rb    # Classe Biblioteca (Gerenciamento do acervo e coleções)
├── app.rb           # Arquivo principal com o menu interativo (CLI)
├── irb-notes.md     # Anotações e evidências de testes no IRB
└── README.md        # Documentação do projeto
