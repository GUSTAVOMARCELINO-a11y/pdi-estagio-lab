# PDI Estágio Lab

Repositório de estudos do meu **Plano de Desenvolvimento Individual (PDI)** de 12 meses na LWSA.

## Sobre

Este repositório documenta meu progresso como **Junior** na equipe de engenharia da LWSA, com foco em Ruby on Rails, práticas de desenvolvimento, e ferramentas da squad cloud.

## Ambiente de Desenvolvimento

### Sistema Operacional
- **Ubuntu 24.04 LTS** (instalação nativa)
- **Processador:** Baseado em x86_64

### Ferramentas Instaladas

#### Essenciais
- **Git 2.43.0** - Controle de versão
- **VS Code 1.122.1** - Editor de código
- **SSH Ed25519** - Autenticação segura com GitHub

#### Linguagens e Runtimes
- **Ruby** - Será instalado via RVM (conforme PDI)

## Como Usar Este Repositório

1. **Clonar o repositório:**
```bash
   git clone git@github.com:GUSTAVOMARCELINO-a11y/pdi-estagio-lab.git
   cd pdi-estagio-lab
```

2. **Explorar os estudos:**
   - Cada mês tem sua pasta com exercícios e aprendizados
   - Commits documentam progresso

3. **Fazer PRs:**
   - Crie uma branch: `git checkout -b feature/meu-estudo`
   - Faça commits significativos
   - Abra PR para revisão
