# Relatório de participação em cerimônias ágeis

## Contexto

- Área: Desenvolvimento de Software
- Squad: Cloud
- Ferramenta: Azure DevOps
- Objetivo: relacionar os conhecimentos adquiridos
  na graduação com a experiência profissional.

## Daily

Durante as reuniões diárias, compartilho o andamento
das minhas atividades, os próximos passos e possíveis
impedimentos técnicos.

Esses alinhamentos ajudam a manter a equipe informada
sobre o progresso das demandas e identificar situações
em que é necessário solicitar apoio.

## Planejamento de demandas

O planejamento permite compreender as prioridades,
os requisitos e os critérios de aceite das atividades.

A organização das demandas no Azure DevOps facilita
o acompanhamento do trabalho e a identificação
de dependências técnicas.

## Revisão de código

O Code Review faz parte do fluxo de desenvolvimento
e contribui para a qualidade das entregas.

A revisão permite receber feedback técnico,
identificar melhorias e compartilhar conhecimento
entre os desenvolvedores.

Embora não seja um evento formal do Scrum, essa
prática contribui para a colaboração da equipe.

## Sprint Review

A Sprint Review tem como objetivo inspecionar
os resultados alcançados e coletar feedback
sobre as entregas realizadas.

## Retrospectiva

A retrospectiva permite identificar oportunidades
de melhoria no processo de trabalho, na comunicação
e na organização das atividades.

## Principais aprendizados

- Comunicar impedimentos com antecedência.
- Manter as demandas atualizadas.
- Compreender os critérios de aceite.
- Solicitar apoio quando necessário.
- Utilizar feedbacks técnicos para evoluir.
- Priorizar a conclusão das atividades.
- Melhorar a comunicação durante as reuniões.

## Oportunidades de melhoria individual

- Melhorar a preparação para as reuniões diárias.
- Desenvolver maior autonomia técnica.
- Aprimorar as estimativas de esforço.
- Manter maior constância no PDI.
- Aprofundar conhecimentos sobre métricas de fluxo.

## Conclusão

O conteúdo estudado na graduação complementa
a experiência adquirida no ambiente profissional.

A aplicação dos conceitos ágeis contribui para
uma melhor organização das demandas, comunicação
com a equipe e melhoria contínua das entregas.
